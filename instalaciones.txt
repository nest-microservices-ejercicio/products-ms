
--- Prisma 6.16

    1. Insalamos Prisma
        pnpm add -D prisma@6.19.0
        pnpm add @prisma/client@6.19.0

    2. Inicializamos Prisma
        pnpm prisma init

    3. Generamos el cliente
        pnpm prisma generate

    4. Migramos la BD
        pnpm prisma migrate dev --name init


--- Microservicios

    pnpm add @nestjs/microservices
